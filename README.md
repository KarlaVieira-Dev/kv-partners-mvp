# KV Partners MVP

Product Intelligence Ecosystem MVP.

## Objetivo

Construir uma plataforma de inteligencia operacional e estrategica capaz de
transformar sinais operacionais, feedbacks, riscos e oportunidades em
recomendacoes acionaveis.

## Modulos

- Executive Center
- Accounts
- Onboarding Center
- Feedback Center
- Risk Center
- Growth Center
- AI Copilot

## Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- shadcn/ui

## Desenvolvimento

Instale as dependencias:

```bash
npm install
```

Rode o servidor local:

```bash
npm run dev
```

Acesse:

```bash
http://localhost:3000
```

Fundacao tecnica do MVP em construcao.
